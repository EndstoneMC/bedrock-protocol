# Go

## Layout

- Build the module `github.com/EndstoneMC/bedrock-protocol/go` in `go/`: the hand-written packages `stream`, `nbt`, `datastore` and `uuid`, the tests' shared assertions in `internal/check`, and the package the schema's `go_package` names, `protocol`, whose hand-written runtime and tests sit beside the files `go generate ./...` writes there.
- Emit one `<module>.bpc.go` per schema module, as protoc-gen-go emits one `.pb.go` per `.proto`, its test-only half as `<module>.bpc_test.go`, and `protocol.bpc.go` and `protocol.bpc_test.go` for what no module owns; open each with `// Code generated by bpc. DO NOT EDIT.`, and let `bpc` delete only stale files of those two suffixes.
- Lay every emitted file out through `gofmt`, which the backend runs on it, with the standard library's imports in a group before the module's; a file `gofmt` rejects fails the compile.
- Name a `stream` read or write `Read` or `Write` and the schema primitive in Pascal case (`ReadUvarint32`, `WriteInt16`), `String` for `str` and `Float` and `Double` for the floats, with `BE` appended for big-endian (`ReadInt32BE`).
- Map a schema builtin `Name` from module `stem` to the type `<module>/<stem without underscores>.Name`, read by `<stem>.Read<Name>` and written by `<stem>.Write<Name>`; the DSL's own `UUID` is `uuid.UUID`.

## Errors

- Return every failure as an `error` and never panic: a decode fails with `stream.ErrTruncated`, `ErrOutOfRange`, `ErrUnknownValue` or `ErrTrailingBytes` inside a `*protocol.DecodeError`, an encode with `ErrOutOfRange` or `ErrUnknownValue` inside a `*protocol.EncodeError`, each carrying the type and the path, field names as `string` and indices as `int`, as C++'s do.
- Fail a `stream.Reader` or `stream.Writer` once: the first `Fail` keeps its reason and offset, a later read returns the zero value and moves nothing, and generated code prepends the field or index where it finds the stream failed.
- Decode in place into the packet given, cleared first, so a failed decode leaves the fields read so far, as protobuf's unfinished message.
- Fail `Encode` and `Decode` with a plain `error` naming the type for a packet with no encoding at the protocol, `protocol.TextPacket_v712: is not a type at protocol 2259`.

## Messages

- Emit each message as protoc-gen-go does: a struct with one exported field per member, named in Pascal case, and a nil-safe `GetX` per field; a struct field is a pointer, nil standing for the default where it is required and for absence where it is optional; an optional scalar is a pointer, a list a slice, an array a Go array and a map a Go map.
- Name a nested type `Outer_Inner`, and a type live at the latest version by its own name and any other with `_v<N>` after its outermost type's name, N the first protocol that holds it (`TextPacket_v898`, `TextPacket_v898_MessageOnly`).
- Hold a union as a oneof: a field typed by the unexported interface `isOwner_Field`, one wrapper struct `Owner_Case` per case holding the case's value under the case's name, `_` appended to a wrapper name another generated name holds, and a `GetCase` getter per case returning the zero value off its case; a nil required union encodes as its first case's default, a nil optional one as its `None` and a nil wrapper as its case's default.
- Wrap a union in a struct of its own, `Owner_Field` holding the oneof as its one field, as a list, array or map element, inside an optional, or beside a union whose case names it shares.
- Name a union case after its value domain, as `java.md` does.
- Fail the compile when a generated type, constant, function or method would equal another, naming the two declarations or union cases that give it.
- Give each encoding of a model an unexported method pair `encode<N>` and `decode<N>` on its message, `Cereal` or `Manual` appended for a non-`Default` key and `Exclude` and the member in Pascal case for an `Exclude<T, &T::member>` one, and call a child's pair by name through the encoding the field's own encoding reaches, never through a selector.
- Give a packet the unexported selectors `encodeAt` and `decodeAt`, and in its test half `caseAt`, one `case` per run of its default-mode encodings, and no other type a selector.
- Encode a map in the order C++ `std::map` holds it: strings by their bytes, numbers by `<`.
- Check a value on encode only where its encoding is narrower than its field, failing one whose cast back differs with `ErrOutOfRange`.
- Decode a required struct to a non-nil pointer, a list and a map to non-nil ones and a name-coded enum to its member's value, so a decoded message compares to a built one through its getters, never through `reflect.DeepEqual`.

## Enums

- Make each enum a defined type over its underlying Go type with one `Enum_MEMBER` constant per member any protocol has, valued by its library value, the maps `Enum_name` and `Enum_value`, `String()`, which spells a value no member has as its number, and `Enum()`; mark a deprecated member `// Deprecated: Do not use.`
- Map a value in `Enum_name` to the name of a pointer sharing it, else to the newest-live member's.
- Keep an int-coded enum open: a field typed by it holds any number of its underlying type, and the protocol's numbering applies on encode and decode.
- Read a name-coded enum field's zero value, which its enum gives no member when another is marked `default=True`, as that member through its getter and on encode, and fail the compile where another of its members holds 0.
- Number and name an enum per protocol through unexported functions beside it, failing a value the protocol cannot number or name with `ErrUnknownValue` on encode, and a number or name it cannot place on decode.

## Protocol

- Declare in `protocol` the `Packet` interface, `PacketId()` and the unexported selectors, so only generated packets implement it.
- Generate a `Pinned` value `V<N>` per modelled protocol in ascending order, with `Version()`, `Encode(packet) ([]byte, error)` and `Decode(data, packet) error`, which rejects trailing bytes, and the root `Encode` and `Decode` as the latest protocol's; generate no lookup by number.
- Generate `ProtocolVersion` with `Protocol()` and `Name()`, naming the first release that shipped it, and `SupportedVersions`, one per release in ascending order, `MinimumVersion`, `MaximumVersion` and `GetProtocolVersion(int) (ProtocolVersion, bool)`, which returns a release's own value and builds one for any other supported number (`protocol/versions.md`).

## Tests

- Check every golden in `goldens_test.go` both ways through the case's `V<N>`, found among the generated `casePins`, finding its type among the generated packets by the id its file name starts with and the one with an encoding at N: decoding the bytes gives the case's value, as the generated `case<N>` methods of the `.bpc_test.go` files write it, and re-encoding gives the bytes.
- Compare a case's value by structure: a number by its value, a `#` and hex pairs against an object of byte members in order, and a literal that the case leaves out as absent.
- Run a test's cases from a table through `t.Run`, the only loop a test holds, named and scoped as `.claude/rules/tests.md` says, with no mocks.
