# Java

- Throw `DecodeException` for bad encoded bytes and nothing else for them; programming errors stay `NullPointerException`, `IllegalArgumentException`, `IllegalStateException` and Netty's own exceptions.
- Catch only `DecodeException`, where a packet enters or to prepend a path segment; never catch `Throwable`, `Error`, `Exception`, `RuntimeException` or `IndexOutOfBoundsException`, and never write an empty catch.
- In a test, catch only the `InvocationTargetException` a reflective call wraps a rejection in, and rethrow every cause it does not handle.
- Create a `DecodeException` through its factories (`truncated`, `outOfRange`, `unknownValue`, `trailingBytes`), as protobuf's `InvalidProtocolBufferException` does; it carries no reason enum.
- Carry the partly decoded message on a `DecodeException`, as protobuf's `setUnfinishedMessage` does: a generated decode sets what its builder holds at the catch that prepends the field, so the outermost message wins.
- Never put encoded text in an exception message.
- Declare every class `final`.
- Annotate every public and protected reference parameter, return and field `org.jetbrains.annotations.NotNull`, or `Nullable` where null is allowed, and add no `package-info.java` for nullness.
- Name a `ByteBufCodec` read or write after CloudburstMC Protocol's, Netty's for a fixed width: `readUnsignedVarInt`, `readVarInt`, `readString`, `readShortLE`.
- Keep `read` and `write` for `ByteBufCodec`'s primitives and the schema's builtins, and name every other type's encoding `encode` and `decode`, NBT tags included.
- Map a schema builtin `Name` from module `stem` to the type `<java_package>.<stem without underscores>.<Name>`, read by `ByteBufCodec.read<Name>` and written by `write<Name>` with `Name` in Google camel case (`readUuid`), with `getDefaultInstance()` and `copy()`; the DSL's own `UUID` is `java.util.UUID`.
- Emit each message as protobuf's generated Java does: an immutable class with `getDefaultInstance()`, `newBuilder()` and `toBuilder()`, a nested `Builder` with `setX`, `clearX` and `build()`, and `getX` on both; `hasX` for an optional, `getXList`, `getXCount` and `addX` for a list, `getXMap` and `putX` for a map, and `getXCase()` for a union.
- Encode a message only through its codecs: nest one per C++ implementation `Serializer<T, N, M>` in its model's class, named `Codec` and its N, as `Codec729`, with `Cereal` or `Manual` appended for a non-`Default` key and `Exclude` and the member in Pascal case for an `Exclude<T, &T::member>` one (`Codec712ExcludeIsRayTracingCapable`), each implementing `Codec<T>` with a `static final INSTANCE`, the class and its instance public only where a codec of another package names it.
- Give a union wrapper the codec names of its owner's encodings that hold its union and no selector, and give a model with no implementation neither codecs nor a selector, except a packet, which keeps its codecs and selector where C++ has none.
- Select a codec with the package-private static `codec(int version, SerializationMode mode)`, one `if` per mode and run the implementation serves as the C++ partials have them, and `codec(int version)` selecting `SerializationMode.DEFAULT`, public on a packet and package-private on any other type; throw `IllegalArgumentException` saying the type is no type at that protocol whatever the mode, and otherwise naming the modes it has there.
- Spell each struct and enum a field names, and call each child's codec by name, `Child.Codec729Cereal.INSTANCE`, through the types the field's own encoding reaches, never at its model's newest protocol or through a selector.
- Build a message's fields and builder from the encoding that holds its model at the newest protocol it covers, and fail the compile when another encoding of the model gives a field another Java type, setter check or enum form, except a field one encoding codes by name and another by number, which the open-form rule settles.
- Hold a union field as a oneof on its message, and wrap a union in a message of its own as a list, array or map element, inside an optional, or beside a union whose case names it shares.
- Name a union case after its value domain, so every encoding of a model keeps one API.
- Default a union to its first case; clearing a required one restores that case, and clearing an optional one gives its `NOT_SET` case.
- Order a map's keys as the C++ `std::map` does: strings by their unsigned bytes, floats by `<`, so `-0.0` and `0.0` are one key.
- Keep an int-coded enum open as protobuf's are: `getXValue()`, `forNumber`, and `UNRECOGNIZED` for a value no member has; `getNumber()` and `getXValue()` are the library value.
- Default a name-coded enum field to the member that its enum's declaration at the newest protocol the message covers marks `default=True`.
- Hold a field typed by the enum itself that one encoding of a model codes by name and another by number in the open form, mapping that int through the naming and throwing `IllegalArgumentException` for a value with no name, and fail the compile for any other such field.
- Emit each literal field as a public constant on the codec of every encoding that writes it, named by its DSL name in upper case without leading underscores (`ACTION_TYPE`), typed by its enum's class, and `@Deprecated` when its member or that member's canonical constant is deprecated.
- Name a packet's id accessor `getPacketId()`, and fail the compile when a generated accessor, selector, codec class or codec constant would equal another generated member.
- Define a type live at the latest version in the bare `java_package`, and any other in the `v<N>` package of the first protocol that held it as `<Name>_v<N>`, `<Name>` being the name the C++ backend declares; a nested type keeps its own name and lives in the model `Schema.owner` names.
- Fail the compile when two generated files would share a path, as two enums' `<Enum>Numbering` in `internal` can.
- Make every enum one class holding every member any protocol has, each member valued by its library value, its number at the newest protocol that has it.
- Keep `SerializationMode` in `<java_package>.internal`, named by no public member.
- Give an enum whose members or numbers change at some protocol, when a field or a literal reaches that numbering, a public `<java_package>.internal.<Enum>Numbering` class that maps a library value to the protocol's number, never in the API; the codec throws `IllegalArgumentException` encoding a value the protocol lacks and `DecodeException.unknownValue` decoding a number it cannot place.
- Check a value on encode only where its encoding is narrower than its field, throwing `IllegalArgumentException` naming the field and the value for one whose cast back differs, or for a packed colour's channel outside 0 to 1.
- Encode and decode a name-coded enum whose names change between protocols with the protocol; encoding a value with no name there throws `IllegalArgumentException`.
- Emit a name ranked after another on a shared value as a `public static final` alias of the constant of a pointer sharing it, else of the newest-live constant, which `forNumber` returns.
- Generate a bare final class `ProtocolVersion` with a private constructor, `getProtocol()`, `getName()` naming the first release that shipped it, and the statics `SUPPORTED_VERSIONS`, one instance per release in ascending order, `MINIMUM_VERSION`, `MAXIMUM_VERSION` and `get(int)`, which returns a release's own instance and builds one for any other supported number (`protocol/versions.md`).
- Generate a bare final class `Protocol` with a private constructor and the static `encode` and `decode` of a packet at the latest protocol, each over a `byte[]` and a `ByteBuf`, with no mode and framing no packet.
- Nest in `Protocol` a `public static final class v<N>` per modelled protocol in ascending order, as the C++ namespace and the Python module `v<N>` are, with a private constructor, `public static final int VERSION` and the same four methods pinned to N, and generate no enum, instance or lookup by number or release.
- Spell every packet in `Protocol`'s registry fully qualified.
- Reach a packet in `Protocol` through its `codec(version)` from one registry of every packet class, and reject a class the registry lacks as a selector does, `<class>: is not a type at protocol <N>`.
- Hold `Protocol`'s class registry in a private holder class, so the first `encode` or `decode` builds it.
- Release the `Unpooled` buffer a `byte[]` overload encodes into in a `finally`.
- Publish the library as `dev.endstone:bedrock-protocol` through the `com.vanniktech.maven.publish` plugin, with a sources jar, a javadoc jar and a POM whose license and developers match `pyproject.toml`, signed whenever `signingInMemoryKey` is set.
- Shape the `nbt` package after Java Edition's `net.minecraft.nbt` under Mojang's mappings: `Tag`, `CompoundTag`, `ListTag`, `NumericTag`, the `valueOf` factories, `getIntOr` accessors and `TAG_*` ids.
- Write a Java source with the checkout's line endings, CRLF where `core.autocrlf` is true, or `spotlessCheck` fails.
- Wrap an emitted Java line that would take its template past ruff's 120 columns after its `(`, with google-java-format's 4-space continuation.
- Write one-line javadoc, only where the signature cannot say it; comment only as CLAUDE.md allows.
- Check every golden in `GoldensTest` both ways through the case's `Protocol.v<N>`, finding its class among the generated packets by the id its file name starts with and the one whose `codec(version)` takes the case's protocol, and through `CaseLoader`, which builds a case's `value` by reflection over the generated builders, reading every form `save` in `tests/conftest.py` writes as conftest's loader reads it and each literal against the codec `codec(version)` selects.
- Reach a package-private selector or codec in a test from its type's package, or through `setAccessible` in `CaseLoader`.
- Anchor an emitted-text assertion in `test_java.py` on its full indentation.
- Log each test's result and a failure's full exception from Gradle's `test` task.
- Test in JUnit 6 under `.claude/rules/tests.md`: a behaviour-named method, one behaviour each, no loop, `if` or `try`, `assertThrows` with the message, `@ParameterizedTest` with `argumentSet` for cases, no mocks.
